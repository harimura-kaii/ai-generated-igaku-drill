# 医学の基礎問ドリル（AI生成・非公式デモ）

解剖生理を中心とした5択問題の演習Webアプリです。**問題と解説はAIが作成しています。**

> **⚠️ 最初にお読みください**
>
> - これは個人が学習のために作った**非公式のデモ版**です。教育機関・医療機関とは一切関係ありません。
> - 問題も解説も**AIが作成**しており、**誤りが必ず含まれます**。正確性は保証しません。
> - **医療行為・診断・治療・服薬などの判断には、絶対に使用しないでください。** 医学的助言ではありません。
> - 国家試験の傾向や合否については何も保証しません。

リポジトリ名に `ai-generated` と入れているのは、URLだけが独り歩きしたときにも
「中身はAI生成である」と伝わるようにするためです。

## このサイトの中心は、問題ではなく「悪問報告」の仕組みです

AIで量産した問題バンクは、どれだけ確認しても一定の割合で悪問——事実の誤り、複数正解になりうる
曖昧な選択肢、不明瞭な設問——を含みます。これは運用でゼロにできる種類の欠陥ではないので、
**「誤りは残っている」という前提のほうを設計に組み込みました。**

すべての問題に報告欄があり、悪問を9分類＋該当箇所＋自由記述で報告できます。報告は問題の正準データに
還流し、修正・再ビルドされて次の版に反映されます。つまりこのサイトは、**使われて指摘されるほど
確実に良くなる**ように作られています。

解いていて「この問題はおかしい」と感じたら、それはあなたが正しい可能性が十分あります。
遠慮なく報告してください。それがこのサイトの想定している使い方です。

### 報告の9分類

| # | 分類 |
|---|---|
| ① | 事実誤り（解説や正解が誤っている） |
| ② | 選択肢が曖昧で複数正解になりうる |
| ③ | 設問文が不明瞭 |
| ④ | 解説が不適切（該当箇所で対象を指定） |
| ⑤ | 日本語用語が不適切 |
| ⑥ | 既存の問題集・過去問と酷似している（版権の懸念） |
| ⑦ | 難易度が不適切（難しすぎる） |
| ⑧ | 難易度が不適切（簡単すぎる） |
| ⑨ | 知識がなくても正解できてしまう（設問文が答えを言っている・選択肢の長さ・言い回しなど） |

⑨は、AIが作った問題バンクに特有の弱点を拾うための分類です。設問文そのものが答えを言ってしまって
いる（「◯◯の外で起こる出血は何か」→「◯◯外出血」のような形）、正解の選択肢だけが不自然に長い、
言い回しが妙に丁寧——こうした手がかりで「知らなくても当てられる」問題は、**答えを知っている
作り手の側からはとりわけ気づきにくく**、解いた人にしか見えません。心当たりがあれば報告してください。

分類に加えて「該当箇所」（設問文／解説全体／選択肢A〜E）を指定でき、⑥では似ている出典も書けます。
どの箇所への指摘かが分かるほど、修正が正確になります。

⑥の報告を受けても、**その場で問題を自動的に取り下げることはしません**。「似ている気がする」の一言で
出題を止められる仕組みは荒らしに弱く、また医学知識の問題は同じ事実を問う以上、構造が似るのは
自然だからです。報告は人間が確認したうえで対応します。

## 問題の作り方（すべて公開しています）

問題は、次の手順で作っています。元資料、指示文の全文、実行の記録、起きた失敗まで、[docs/](docs/) に公開しています。

1. **出題範囲の設計図（ブループリント）を先に作る。** 文部科学省「医学教育モデル・コア・カリキュラム（令和4年度改訂版）」を元に、解剖生理で問うべき知識を 2,890項目に分解しました。
2. **項目ごとに AI が問題を作る。**
3. **別の AI が審査する。** 2種類の AI が互いを見ずに欠陥を探し、指摘を参考に最終判定します。意見が割れたら3人目が裁きます。
4. **落ちた問題は、指摘を付けて作り直す。** 3回作っても通らない問題はあきらめます。

最初に作った約6,000問のうち、1回目の審査で通ったのは 82% でした。

- 短い説明: [このサイトの問題はどう作られているか](docs/00_このサイトの作り方.md)
- 概要と目次: [docs/README.md](docs/README.md)
- AI に読ませる場合: [docs/llms.txt](docs/llms.txt)

以前の版（神経系 511問）で使っていた審査の道具は、別のリポジトリで公開しています: [agent-roundtable](https://github.com/harimura-kaii/agent-roundtable)

## 既知の限界

- **人の専門家は内容を確認していません。** ブループリントも問題も、作ったのも審査したのも AI です。
- **AI の審査を通ったことは、正しいことの保証ではありません。** 審査する AI にも誤りがあります。
- **範囲は「ほぼ全部」です。** 2,890項目すべてに問題がありますが、28項目では、作る予定だった切り口のうち1つが欠けています。
- **難易度の表示はありません。** 作るときに使った水準の区分（想起／機序の説明／状況への適用）は、難しさの目安としては使えないと分かったため、画面には出していません。
- 以前の神経系 511問は、2026年10月に今回の方式で作り直した問題に置き換えました。問題番号も変わったため、以前の神経系の成績と進捗コードは引き継がれません。

詳しくは [docs/04_見直しと限界.md](docs/04_見直しと限界.md) を見てください。

## 主な機能

- **範囲選択**: 単元をまたいだ分類ツリーから出題範囲を選択（折りたたみ式・範囲ごとの進捗表示つき）
- **出題設定**: 回答状況、出題数、シャッフル、選択肢ごとの解説の表示切替
- **採点モード**: 1問ずつ答え合わせ／最後にまとめて採点（レビュー画面つき）
- **制限時間**: なし／1問ごと／セット全体
- **苦手分野の割り出し**: リーフ（復習できる最小単位）ごとの正答率集計
- **進捗コード**: 学習記録を短い文字列にして別の端末へ持ち運べます（後述）

## 進捗コード（「ふっかつのじゅもん」方式）

このサイトはサーバーを持たない静的サイトで、学習記録はブラウザのlocalStorageにのみ保存されます。
そのままでは別の端末に引き継げないため、回答記録を短い文字列にエンコードして持ち運べるようにしました。

- 記録するのは「どの問題に、どの選択肢で答えたか」だけです
- チェックサムを持たせているので、書き間違えたコードは弾かれます
- **本人確認の仕組みではありません。** 自己申告レベルの識別に過ぎず、工夫すれば書き換えも可能です。
  試験の記録や成績証明としては使わないでください

## 技術構成

- 依存ライブラリなし（Vanilla JS）。ビルド不要、静的ホスティングのみで動作します
- サーバーを持たないため、成績・報告はすべて利用者の端末内（localStorage）に保存されます
- 悪問報告のみ、設定されていればGoogleフォームへ送信されます（`report-config.js`）
