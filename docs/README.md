# この問題集の作り方（概要）

「医学の基礎問ドリル」の解剖生理 6,026問は、すべて AI が作り、AI が審査したものです。人の専門家による内容の確認は入っていません。
このページでは、何を元に、どういう手順で作り、どこに限界があるかを、10分ほどで読める分量でまとめます。
詳しい記録と、使った指示文・データの全文は、下の目次からたどれます。

## 3行で

1. **出題範囲の設計図（ブループリント）を先に作りました。** 文部科学省の医学教育モデル・コア・カリキュラム（令和4年度改訂版）を元に、解剖生理で問うべき知識を 2,944項目に分解したものです。
2. **項目ごとに AI が問題を作り、別の AI が審査しました。** 審査で落ちた問題は、指摘を付けて作り直します。3回作っても通らない問題はあきらめます。
3. **それでも誤りは残っています。** だから、すべての問題に報告欄を付けています。

## 作り方の流れ

```
コアカリ（文部科学省）
   │  解剖生理に当たる表・学修目標を抜き出す
   ▼
ブループリント  12系統・50群・2,944項目
   │  1項目 ＝「知識」＋「この項目で何を問うか」＋「水準 L1／L2／L3」＋「典拠の番号」
   ▼
生成        Claude Opus 5.5 が、1項目から1問〜数問を作る
   ▼
指摘出し    Claude Sonnet 5.5 と GPT-6 Luna が、互いを見ずに2回ずつ欠陥を探す
   ▼
裁定        Sonnet と Luna が、指摘を参考に最終判定する
   │  ├ 事実・正解の一意性・解説などの指摘が1つでもあれば棄却
   │  └ 「誤答が弱い」「水準が合わない」で2者が割れたら控訴審（Opus）へ
   ▼
採用 ／ 棄却 → 指摘を付けて作り直し（最大3周）→ 通らなければ打ち切り
```

水準は、難しさではなく「解くのに必要な頭の使い方」の種類です。
L1 は事実を思い出す、L2 は機序や理由を説明する、L3 は提示された状況（検査値や経過）に当てはめて判断する、の3段です。

## 数字で見る

| | |
|---|---|
| ブループリント | 12系統・50群・2,944項目（L1 733／L2 1,776／L3 435） |
| 収録した問題 | 6,026問。2,944項目すべてに1問以上（1項目あたり平均2.0問）。2026年10月9日の追補（54項目・80問）を含む |
| 最初に作った問題 | 5,974問。うち1回目の審査で通ったのは 4,874問（82%） |
| 作り直し | 2周目 1,100問中 885問、3周目 215問中 144問が通過 |
| 打ち切り | 71問（70項目）。あとで原因を調べ、49問を作り直して 42問を追加 |
| かかった時間 | 全範囲の実行に約34時間（2026年10月6日夜〜8日朝） |
| AI の呼び出し | 約47,000回（Sonnet 22,345／Luna 21,801／Opus 3,217） |

審査で多かった指摘は、「解説の誤り・言い過ぎ」（689問）、「水準のずれ」（582問）、「事実の誤り」（308問）、「正解が1つに決まらない」（302問）、「誤答が弱い」（180問）でした（1問に複数の指摘が付くことがあります）。

## 知っておいてほしい限界

- **人の専門家は内容を確認していません。** 作者は医学の内容を判断できる立場にありません。審査はすべて AI です。
- **AI の審査を通ったことは、正しいことの保証ではありません。** 審査員の AI にも誤りがあり、2種類の審査員は厳しさが4倍以上違いました。
- **範囲は「ほぼ全部」です。** 項目は全部に問題がありますが、28項目では、作る予定だった切り口のうち1つが欠けています。
- **コアカリの読み落としが残っている可能性があります。** 資料の選び漏れが後から見つかり、補った経緯があります。
- **水準（L1〜L3）は難易度の目安としては使えません。** とくに L2 は、基礎から応用まで幅があります。サイトでは難易度として表示していません。

詳しくは [見直しと限界](04_見直しと限界.md) にまとめています。
