# 01 ブループリントの作り方

ブループリントは、「どの知識を、どの水準まで問うか」の一覧です。問題を作る前にこれを決めておくことで、出題の網羅と水準に根拠を持たせます。
8月の時点で 12系統・50群・2,890項目になり、2026年10月9日の追補（54項目）で 2,944項目になりました。全文は [blueprint/](blueprint/) と [data/blueprint.json](data/blueprint.json) にあります。

## 元にした資料

資料は1本だけです。

- **医学教育モデル・コア・カリキュラム（令和4年度改訂版）**
  文部科学省／モデル・コア・カリキュラム改訂に関する連絡調整委員会。令和6〜11年度の入学生に適用。本文 293ページ。
  https://www.mext.go.jp/a_menu/koutou/iryou/mext_00005.html

公開されている PDF の本文から、該当する記載を抜き出して使いました。ただし、抜き書きは原文を縮めた箇所があり、1か所は内容まで違っていました（下の「起きた失敗と対処」）。
教科書、医師国家試験出題基準、国家試験の過去問は使っていません（出題基準は中身を確認していません）。

使ったのは次の部分です。ブループリントの各項目に付いている「典拠」の番号は、これらを指します。

| 番号の形 | 指すもの |
|---|---|
| 表2-1 〜 表2-15 | 第2章の系統別の表のうち「構造と機能」の欄。例: 表2-2 神経、表2-5 循環器、表2-7 消化器、表2-13 内分泌・栄養・代謝 |
| 表2-N(症候) | 同じ表の「症候」の欄。L3（状況への適用）の問題で、提示する状況の材料として参照 |
| PS-01-01、PS-01-02、PS-01-03 | 「個体の構成と機能」「個体の反応」の学修目標。細胞、組織、膜輸送、恒常性、代謝、発生、免疫など |
| GE-03 | 成長・発達・老化、思春期に関する学修目標 |
| 表6、実習GL(医行為の例示) | 血液型の群だけで使用。表6 は主要な臨床・画像検査の表。実習GL は、同じ冊子の「診療参加型臨床実習実施ガイドライン」にある医行為の例示の表（2026年10月9日までは誤って「表7」と表記していた。[対応表](blueprint/curriculum_map.md) に経緯） |

コアカリのどの記載をどの群に渡したかは、[コアカリとブループリントの対応](blueprint/curriculum_map.md) に一覧があります。

コアカリは臨床医学も含みますが、疾患や治療を答えさせる項目は作っていません。範囲は解剖生理に限っています。

## 群の分け方

先に、解剖生理の分類の骨組み（12系統・50の中分類）を作ってありました。AI が案を作り、作者が目を通して承認したものです。
この50の中分類を、そのまま「群」として使いました。各群に、コアカリの該当する表や学修目標を割り当てています。

## 1項目の形

| 欄 | 中身 |
|---|---|
| 番号 | 例 `4.1-01`（群の番号と通し番号） |
| 知識 | 何についての項目か |
| 問える単位 | この項目で何を問うか。「〜を説明できる」「〜を判断できる」の1文 |
| 水準 | この項目で到達すべき水準の上限。L1／L2／L3 のどれか1つ |
| 典拠 | コアカリの表・学修目標の番号（必須） |
| 根拠 | その水準にした理由 |

**水準の定義**

- **L1 想起**: 事実そのものを知っているか。
- **L2 解釈**: 機序・理由を説明できるか。
- **L3 適用**: 検査値の組合せ、経過、症例などの具体的な状況を読んで、知識から答えを導けるか。

迷ったら L2 にします。ブループリントの分類としては、機序の説明は、どれだけ複雑でも L2 です（問題を作る段階では別に、L2 の問題は「1段たどれば決まる」重さに抑えるよう指示しています）。L3 にするのは、具体的な状況を置いた問いが作れる項目だけです。
語の成り立ちを読めば解ける問い（「硬膜の外で起こる出血は何か」→ 硬膜外出血）は、どの水準でも作ってはいけないものとしました。

## 作る手順（5工程）

| 工程 | 内容 | 担当 |
|---|---|---|
| 0 資料を決める | 群ごとに、コアカリの該当箇所を抜き出して渡す。起草する AI に各自で検索はさせない | 人と Claude |
| 1 独立に起草 | 2つの AI が、互いの案を見ずに項目の一覧を作る | Claude Opus と GPT-5.6 Sol |
| 2 ダメ出し | 2本の草稿に、両方の AI が指摘する。観点は「網羅」「粒度」「水準」「典拠との整合」の4つに固定 | Opus と Sol |
| 3 弁護 | 片方だけが出した項目について、**出さなかった側**が「残すべきか」を判定する | Opus と Sol |
| 4 統合と検査 | 1本にまとめ、機械検査にかける | Sol、検査スクリプト |

**なぜこの形にしたか。** 2つの AI の案が食い違う所こそ、独立に作らせた価値がある場所です。ところが、どちらを採るかを当事者に決めさせると、自分の案に倒れます。
そこで採否は、「コアカリの番号に紐づいているか」という確かめられる事実と、「提案しなかった側の弁護」で決めることにしました。
各 AI に個別の検索をさせないのも同じ理由です。差が「判断の違い」なのか「見た資料の違い」なのか、区別できなくなるためです。

**統合の決まり**（要点）

- 2本に共通する知識は残す。両方が見落としていたと指摘されたものは足す。
- 典拠に無い、範囲外と指摘されたものは落とす。
- 水準の指摘が食い違ったら、控えめな L2 側を採る。
- 片方だけの項目は、弁護で「残す」とされたものだけ残す。

**機械検査**（AI は使わない）

必須の欄がそろっているか、番号が連番か、典拠の番号がその群に渡した資料に実在するか、項目の重複や埋め草の文字が無いか、L3 なのに「問える単位」に具体的な状況の手がかりが無くないか、を確かめます。
検査するのは形式です。**医学的な内容の正しさは、機械検査では見ていません。**

## 粒度の決まり（作問してから分かったこと）

内分泌の最初の群で実際に問題を作ってみて、2つの決まりを足しました。

1. **1項目に、水準の違う内容を同居させない。** 「名称と分類の対応」（L1）と「機序の説明」（L2）が同じ項目にあると、問題を作る AI は、楽な L1 の側だけを問う問題を作りがちでした。別の項目に分けます。
2. **「問える単位」を広く書かない。** 「〜が起こる理由を説明できる」のような書き方では、向きの対応を覚えているだけで解ける問題になります。何と何の関係として説明させるかまで書き切ります。

コアカリの1行はとても粗いので（1行で内分泌全体を指すものもあります）、問える単位まで分解することが、この作業の本体でした。
項目の文面は、コアカリの写しではありません。8月に作った全2,890項目を機械的に比べたところ、コアカリの原文と共通する連続部分は最大で14字（用語が重なる程度）でした。

## 起きた失敗と対処

- **水準の定義があいまいで、2つの AI が別の解釈をした。** 最初の群で L3 の定義が言葉だけだったため、判定の基準を「設問に具体的な状況が置かれるか」という操作的な形に書き直して、やり直しました。
- **資料の選び漏れ。** 成長・老化の群で「該当する資料なし」としていましたが、コアカリの別の章（GE-03）を読み落としていました。乳房、喉頭、血液型でも、別の表に該当箇所がありました。
  工程0で資料を落とすと、あとの2つの AI は同じ穴に気づけません。以後、「範囲外」「資料なし」と判断するときは、原本のページと確かめた範囲を添えることにしました。
- **抜き書きが原文と違っていた。** 2026年10月に、渡した記載をコアカリ本文と機械で照合し直しました。22か所で文言が原文と違い、多くはかっこ書きや細目の省略でしたが、小児期の発達の目標（GE-03-02-01）は内容が違っていました。また、血液型の群で「表7」とした典拠は番号の付け間違いで、正しくは同じ冊子の別の表でした。渡していなかった記載も10行見つかりました。すべて [コアカリとブループリントの対応](blueprint/curriculum_map.md) に載せています。同じ日に、典拠の表記を付け替え、解剖生理に当たる5行ぶんの項目と問題を足しました。
- **典拠が無いのに AI が項目を作った。** 血液型の群で、渡した資料が薄かったとき、片方の AI は一般知識から13項目を作り、関係のない表の番号を典拠に付けました。もう片方は「作れない」と正しく断りました。典拠の必須化と機械検査で防いでいます。
- **AI が出力例をそのまま返した。** 呼び出しに失敗したとき、指示文の中の出力例がそのまま返り、実データとして取り込まれかけました。埋め草を検出する検査を足しました。

## 記録が残っていないもの

- この工程のトークン数と、群ごとの所要時間は記録していませんでした。呼び出しは記録のある分で約440回です。
- 分類の骨組みを作った日付と経過は、記録が見つかりませんでした。

## 限界

- **人による医学的な監査はありません。** 機械検査と、複数の AI の相互批評だけです。
- 資料はコアカリの一部の表と章だけです。選び漏れが残っている可能性があります。
- 内分泌系の群では、松果体、消化管ホルモン、心房性ナトリウム利尿ペプチドなどを内分泌の項目として取り上げるかを保留したままです（消化管ホルモンや利尿ペプチドは、消化器・循環器の群には項目があります）。
- 老化の群は、コアカリの記述が1行しか無いため、4項目だけです。
