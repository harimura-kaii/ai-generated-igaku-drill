# コアカリとブループリントの対応

「医学教育モデル・コア・カリキュラム（令和4年度改訂版）」（文部科学省）のどの記載が、ブループリントのどの群の元になったかを示す表です。

## 読み方

- ブループリントは50の群に分けて作りました。群を作るとき、AI には「この群はコアカリのこの記載を元にする」と、該当する記載だけを抜き出して渡しています。この表は、その控えをコアカリ本文に引き当てて並べたものです。
- 対応が分かるのは **コアカリの記載 → 群** までです。項目1つ1つがどの行から出たかは記録していません。コアカリの1行は「血小板の機能と止血や凝固・線溶の機序」のように粗く、1行から数十項目に広げているためです。
- 同じ表を分け合う群（神経の3群、循環器の3群など）には、表の「構造と機能」の欄を丸ごと渡し、どの行を自分の群で扱うかは AI に判断させました。そのため、1つの行に複数の群が並ぶことがあります。行ごとに分けて渡した群（血液、消化器、腎など）では、行と群が1対1に近くなります。
- 「項目数」「問題数」は、その表・学修目標を典拠に挙げている項目と、そこから作って採用した問題の数です。複数の典拠を挙げる項目は、それぞれで数えています。
- 記載の文言と表題・ページは、[コアカリ本文の PDF](https://www.mext.go.jp/content/20240220_mxt_igaku-000028108_01.pdf) から機械で抜き出したものです。ページは文書に印刷されている番号です。
- AI に渡した文言は、原文を縮めた抜き書きでした。原文と違っていた箇所は、末尾の「渡した文言と原文の違い」に全部載せています。
- 「2026-10-09 に追補」「2026-10-09 に典拠を付け替え」とある対応は、2026年10月にコアカリ本文と照合し直したあとで足したものです（末尾の「照合で見つかった誤りと対処」）。
- 逆向き（群 → コアカリ）は、[系統ごとのブループリント](./) の各群の見出しの下に載せています。

全体では、コアカリの 240 の記載を50群に渡し、2,944項目に展開しました。
