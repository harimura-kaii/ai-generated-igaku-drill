**注意**: 上の指摘は**参考情報**です。指摘が正しいとは限りません。

# 機械検査の印（字数・形式の目安超え）

【機械検査の印（無ければ「なし」）】

**これは不合格の判定ではなく、目安を超えたという印です。** 字数や形だけを理由に落とさないでください。
落とすのは、その長さ・形が**解答に効かない読解・照合の負荷**になっている場合だけです（⑪）。
具体的な状況を読ませる問題など、**長さに必然があるなら欠陥ではありません**。
審査対象の `note` に作問者が原則を曲げた理由を書いていることがあります。理由が妥当なら尊重してください。

# 判定分類

- **①事実誤り** — 正解とされる選択肢が実際には誤り、または設問・解説に明白な事実誤認がある
- **②選択肢曖昧** — 複数の選択肢が正解になりうる、または一意に定まらない
- **③設問不明瞭** — 設問文の意味が曖昧・不完全
- **④解説不適切** — 解説や各選択肢の理由が誤り・矛盾・説明不足
- **⑤日本語不適切** — 用語や言い回しが不自然・誤用
- **⑥極端に弱い誤答** — **L2/L3 を狙った問題で**、対象読者がほとんど医学知識を使わず、
  常識・露骨な因果の破綻・設問文との明白な矛盾だけで複数の誤答を捨てられ、正解が不適切に目立つ。
  単に消去法が使えること自体ではなく、**誤答が真剣な候補として機能していない場合**のみ該当。
  単純な想起（L1）の問題には適用しない（同じカテゴリの用語が並んでいれば足りる）。
  **知識がなければ捨てられない誤答が2つ以上残っている（実質3択として機能する）なら、⑥としない**
- **⑨宣言と実効の乖離** — 宣言された水準と、実際に解くのに必要な水準が食い違っている（**軽すぎ・重すぎの両方**）
- **⑩出題意図からの逸脱** — この問題が、宣言された「問うべき内容」の**どの要素も**まともに問えていない、
  または内容の外にあることを問うている。
  **「問うべき内容」に複数の要素があるとき、1問が担当するのはそのうち1つでよい**（作問側は
  要素ごとに問題を分けるよう指示されている）。この問題が要素の一部しか扱っていないことだけを理由に
  ⑩としないこと。項目全体として抜けている要素があれば、判定とは別に `coverage_gap` に書く
- **⑪過剰な負荷** — 解答に効かない情報、長文の選択肢どうしの突き合わせ、正解だけが形で目立つなど、
  **医学知識と無関係な読解・照合・形式の手がかり**が解く作業の中心になっている

# 判定の手順（順序を守ること）

**段1: まず宣言を見ずに、事実関係だけを独立に検証する。**
正解とされる選択肢が本当に正しいか、解説に誤りがないかを、自分の知識だけで確かめる。
ここで「宣言によればこれが正解のはずだ」という推論を使わないこと。

**段2: 段1で列挙した「実際に必要な知識と操作」が、宣言された認知レベルと問うべき内容に
見合うかを確かめる。**軽すぎても重すぎても**見合っていない。見合わなければ ⑨ または ⑩ に該当する。**

**段3: 上記を踏まえて判定する。**

# 注意

- **消去法が効くこと自体は欠陥ではない。**鑑別は本来消去法である。
  ただし、**医学知識をほとんど使わずに複数の誤答を捨てられる**なら、それは⑥（極端に弱い誤答）である。
  **⑥と⑨は別物として付けること**: 問いの立て方そのものが宣言と違う水準を測っているなら⑨、
  問いは宣言どおりだが誤答が弱いせいで楽に解けるなら⑥、両方なら両方
- **用語が字面で意味を漏らすこと自体も欠陥ではない。**咎めるのは設問文がその字義を提示している場合
- ここは最終判定なので、**一次のような「迷ったらフラグ」ではなく、根拠を持って判定すること**
