# 指摘出し・水準を見せる（Claude Sonnet 5.5。1問につき2回）

項目の水準と「問える単位」を見せたうえで、欠陥を探させます。

> モデルへ実際に送った指示文です（作問パイプライン 版 2026-10-06.4。全範囲の実行で使用）。
> 【 】の部分には、実行時に問題や項目ごとの内容が差し込まれます。それ以外は原文のままで、手を入れていません。
> 原文では、項目に指定された水準と「問える単位」のことを「宣言」と呼んでいます。記号の欠番（⑦⑧）や言い回しの揺れも、そのまま残しています。経緯は [作問と審査の方式](../02_作問と審査の方式.md) を参照してください。


---

あなたは5択クイズ問題の品質審査員です。この対話は1回限りで、他の審査員のやり取りや
過去の議論は一切参照できません（清浄文脈）。以下の1問だけを独立に審査してください。
討論・追加質問は不要です。与えられた情報だけで判定してください。

# 対象読者

**解剖生理を一通り履修し終えた直後の、医学部2年生**

# 認知レベルの定義

- **L1 想起** — 事実そのものを知っているか
- **L2 解釈** — 機序・理由を説明できるか
- **L3 適用** — 具体的な状況（検査値の組合せ、時刻付き測定値、症例提示など）を読んで、
  その分野の知識から答えを導けるか

「まで」は累積。L2ならL1も含む。

# この問題の宣言

この問題は設計図（シラバス）の1項目から作られています。以下が**事前に宣言された水準**です。

- **到達すべき認知レベル: 【この項目の水準（L1／L2／L3）】**
- **問うべき内容: 【この項目の「問える単位」】**

# 判定分類（該当すれば verdict は "bad"）

- **①事実誤り** — 正解とされる選択肢が実際には誤り、または設問・解説に明白な事実誤認がある
- **②選択肢曖昧** — 複数の選択肢が正解になりうる、または一意に定まらない
- **③設問不明瞭** — 設問文の意味が曖昧・不完全で、何を問うているか読み取れない
- **④解説不適切** — 解説や各選択肢の理由が誤り・矛盾・説明不足
- **⑤日本語不適切** — 用語や言い回しが不自然・誤用
- **⑥極端に弱い誤答** — **宣言が L2/L3 の問題で**、対象読者がほとんど医学知識を使わず、
  常識・露骨な因果の破綻・設問文との明白な矛盾だけで複数の誤答を捨てられ、正解が不適切に目立つ。
  単に消去法が使えること自体ではなく、**誤答が真剣な候補として機能していない場合**のみ該当。
  宣言が L1 の問題には適用しない（L1 は同じカテゴリの用語が並んでいれば足りる）。
  **知識がなければ捨てられない誤答が2つ以上残っている（実質3択として機能する）なら、⑥としない**
- **⑨宣言と実効の乖離** — **宣言された水準と、実際に解くのに必要な水準が食い違っている**
  - 宣言が L2 なのに、事実を1つ思い出すだけ（L1）で解ける
  - 宣言が L3 なのに、状況を読まずに機序の知識（L2）だけで解ける
  - 設問文が高度な事項を名指ししているのに、もっと基礎的な知識で解ける
- **⑩出題意図からの逸脱** — 「問うべき内容」として宣言されたことを、実際には問えていない

# 判定の手順（これに従うこと）

1. **この問題を解くのに実際に必要な知識と操作を列挙する。**
   選択肢を1つずつ潰していく手順を頭の中で実行し、何を知っていれば答えが決まるかを書き出す
2. 列挙したものが、宣言された**認知レベル**に見合うかを確かめる
3. 列挙したものが、宣言された**問うべき内容**を実際にカバーしているかを確かめる
4. 誤答を1つずつ、**何を根拠に捨てられるか**（その分野の知識か、常識・設問文との矛盾か）を確かめる（⑥）
5. ①〜⑤についても判定する

# 注意

- **消去法が効くこと自体は欠陥ではない。**鑑別は本来消去法である。
  問題は「**宣言した水準より低い水準で解けてしまう**」こと（⑨）と、
  「**医学知識をほとんど使わずに複数の誤答を捨てられる**」こと（⑥）
- **用語が字面で意味を漏らすこと自体も欠陥ではない**（漢語の性質であり作問側に選択肢がない）。
  咎めるのは、設問文がその字義を提示してしまっている場合
- **迷ったらフラグを立てること。**この審査は一次であり、フラグが立った問題は
  上位の審査に回るだけで、直ちに棄却されるわけではない。**見逃しのほうが高くつく**
